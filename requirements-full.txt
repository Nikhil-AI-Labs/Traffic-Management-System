# Surat Traffic Intelligence — full local pipeline dependencies.
#
# Everything in requirements.txt, plus detection and tracking. Use this to run
# the pipeline end to end from raw video:
#
#     python scripts/download_models.py     # UVH-26 YOLO11 weights, ~55 MB
#     python src/analyze.py --all           # detect → track → measure → CSV
#     python src/calibrate.py <camera>      # interactive polygon tracer
#
# Standalone rather than `-r requirements.txt`, because the two files pin
# different OpenCV builds and pip would install both into the same `cv2`:
#
#     requirements.txt        opencv-python-headless   no GUI, no libGL needed
#     requirements-full.txt   opencv-python            GUI, needed by calibrate.py
#
# src/calibrate.py traces lane polygons by hand through cv2.imshow and a mouse
# callback, so the local set needs the GUI build. Installing both leaves
# whichever landed last in place, which is how you get a calibration tool that
# opens no window and raises nothing.
